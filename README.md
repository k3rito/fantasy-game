# Ashen Frontier

A browser-first open-world RPG prototype by **K3RITO**.

## Features
- Third-person 3D exploration with WASD
- Open-world procedural wilderness prototype
- Quest loop and XP/level progression
- Skill tree with unlock points
- Field tools: grapple, scout drone, ember torch
- World map overlay
- Responsive dark fantasy HUD

## Run locally
```bash
npm install
npm run dev
```
